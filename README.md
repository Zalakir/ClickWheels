# ClickWheels

---

ClickWheels is a lightweight tool that automatically performs mouse clicks at customizable intervals, designed for auto-clicker games.

## Features
- Start and stop clicking with the hotkey T
- Adjust the click interval from the on-screen slider

## Requirements
Make sure Python is installed, then install the required packages:

Bash:
- pip install pynput
- pip install pyautogui
- pip install Pillow

## How to Run
1. Open the project folder.
2. Run the script ClickWheels.py
3. Use the GUI controls or press T to toggle clicking.

## Notes
- The app uses a small keyboard listener, so it can be toggled quickly while working.
- On Windows, the program will try to relaunch itself with pythonw.exe so only the application window is shown.

Enjoy using ClickWheels!
